# MG3
## Devlog
1. The default values for floats and ints are 0 while the default value for bool is false and the default value for string is an empty value.
2. The Update method does not get called in the code as it is a built in method by Unity so it runs and gets called in the game engine every frame.
3. The TimerText class uses the timer to keep track of how much time the game has before ending and it uses the Update method to update the timer every frame by decreasing it with Time.deltaTime.
